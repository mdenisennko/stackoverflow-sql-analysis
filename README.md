# Анализ пользовательской активности Stack Overflow

## О проекте

SQL-проект по анализу пользовательской активности и метрик вовлеченности на данных Stack Overflow.

В рамках проекта написала 20+ аналитических SQL-запросов к связанным таблицам базы данных.

## Задачи

В проекте исследовались:

- пользовательская активность;
- динамика активности во времени;
- метрики вовлеченности;
- сегментация пользователей;
- накопительные показатели;
- изменение метрик по месяцам.

## Использованные SQL-инструменты

- JOIN
- CTE
- оконные функции
- RANK
- LAG
- SUM OVER
- AVG OVER
- агрегирование
- работа с датами и интервалами

## Навыки

- аналитический SQL;
- работа с реляционными базами данных;
- расчет пользовательских метрик;
- сегментация пользователей;
- анализ динамики показателей.

## Стек

**SQL, PostgreSQL**
